# PZMod_Longsword
This is my first attempt on a mod, so wish me luck.

## How to set up the mod

1. Download the repository.
2. Copy the SLs folder.
3. Find your zomboid folder(This should be in your user folder).
4. Open the folder and find the mods folder.
5. Open the mods folder and paste the SLs folder inside of it.
6. That should be it, however to activate the mod open project zomboid go to start a new game, there you should see a choose mod button.
7. Press it and you should see a menu of all the mods that you have, then you click and choose who to activate so activate Smash Longsword.
8. And you are done, just be careful because your mod will not be updated if done the way you did now. Therefore you  maybe should consider using the steam workshop instead, if its been posted there.

## What the mod does
What this mod does is add a new longsword to the game.
It proceduraly generates it in places that you may be able to find it. Lastly it contains a book that when read learns you the recipe to make the longsword.
